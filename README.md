# Task 26 — Sales Data Visualization Using Python

## Project Overview

This project demonstrates sales data visualization using Python, Pandas, and Matplotlib.

It uses a sample monthly sales dataset covering three product categories: Electronics, Clothing, and Furniture.

A bar chart is created to compare sales by product category, while a line chart is used to visualize monthly sales trends and identify patterns.

## Objectives

- Load and inspect a sales dataset using Pandas.
- Create a bar chart to compare product categories.
- Create a line chart to analyze monthly sales trends.
- Identify the highest and lowest selling categories.
- Identify monthly sales patterns.
- Record meaningful observations from the visualizations.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab
- GitHub

## Dataset Description

The dataset contains 36 sample sales records covering January to December 2025.

It includes three product categories:

- Electronics
- Clothing
- Furniture

The dataset contains the following columns:

| Column | Description |
|---|---|
| month | Month of the sales record |
| category | Product category |
| sales_inr | Sales amount in Indian Rupees |

The data is illustrative and manually created for this educational assignment. It does not represent actual company transactions.

## Visualizations

### 1. Bar Chart — Sales by Product Category

The bar chart compares total annual sales across Electronics, Clothing, and Furniture.

### 2. Line Chart — Monthly Sales Trend

The line chart displays the total sales for each month during 2025 and helps identify changes and trends over time.

## Key Observations

- Electronics generated the highest sales at ₹19,23,000.
- Furniture generated the lowest sales at ₹10,23,000.
- December had the highest monthly sales at ₹4,63,000.
- January had the lowest monthly sales at ₹2,75,000.
- Monthly sales increased approximately 68.36% from January to December.
